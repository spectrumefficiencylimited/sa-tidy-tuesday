4 Cognitive Signature

  • Start by naming the question and the unit of analysis before choosing plots or metrics.
  • Use schema inspection to decide which table carries the main story and which tables are support tables.
  • Treat data collection as its own stage; assemble or scrape context first, then interpret.
  • Build one analysis-ready table before comparing groups so the narrative rests on a stable grain.
  • Start broad with time or trend structure when it helps explain which later comparisons are fair.
  • End with one communication-ready chart or table that carries the episode’s main claim.
